# Community Resources

Connect with the Planar community for support and collaboration.

## Getting Help

- **GitHub Issues** - Report bugs and request features at [github.com/BubbleParticles/Planar.jl/issues](https://github.com/BubbleParticles/Planar.jl/issues)
- **Discord** - Join the community chat: [![Discord](https://img.shields.io/discord/1079307635934904370)](https://discord.gg/xDeBmSzDUr)

Before opening an issue, review [Creating Effective Bug Reports](../troubleshooting.md#Creating-Effective-Bug-Reports) so your report includes the information maintainers need.

## Contributing

Planar welcomes contributions. See `docs/CONTRIBUTING.md` in the repository for guidelines on:

- Setting up the development environment
- Running the test suite
- Submitting pull requests
- Documentation contributions
